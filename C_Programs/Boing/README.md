# Boing

This code was written by **Jimmy Maher** (<http://amiga.filfre.net>) as a
five-stage reconstruction of the original 1984–85 Amiga Boing demo by Dale Luck
and R.J. Mical.

All I did here was fix some compiler warnings so it builds under **Kickstart
2.05 and SAS/C 6.0**, plus a few minor issues. The credit for the program itself
belongs entirely to Jimmy Maher.
